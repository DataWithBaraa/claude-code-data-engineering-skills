The data architecture in detail

Every layer, gate and record, from the sources to the consumers.

the 4 gates

  • 1the file: manifest, checksum, header. File quarantined.
  • 2the rows: readable lines, columns, types. File quarantined.
  • 3the row rules: code lists, postal codes, sequences. Row quarantined.
  • 4the tables: keys, parents, a complete feed. Gold not built.

the layers

  • landing: baseline, daily feed and month-end export, never edited
  • bronze: append only, every value as text
  • silver: clean one row per key, then the business entities
  • gold: star schema and one big table, built only when the gates pass

around it

  • sources: 6 csv, finance in xlsx, support in json, crm and web in jsonl
  • generated from the data contracts: bronze and silver_clean. The rest is hand-written
  • the daily run: run/daily.py at 05:30 UTC, 12 min 12 s
  • month end: every clean table against the export
